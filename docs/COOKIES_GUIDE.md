# Инструкция по экспорту и настройке cookies.txt для YouTube Music

Для того чтобы **SyncWave** мог скачивать треки из ваших приватных плейлистов, контент с возрастными ограничениями и, самое главное, ваш системный плейлист **«Понравившиеся»** (`LM` / Liked Songs), демону необходим файл авторизационных куков `cookies.txt`.

---

## Зачем нужны куки?

YouTube защищает приватную информацию пользователя (лайки, персональные подборки, историю) авторизационными HTTP-куками (`SAPISID`, `SSID`, `HSID`, `LOGIN_INFO` и др.). Без них YouTube Music возвращает ошибку `401 Unauthorized` или сообщает, что плейлист не найден.

---

## Пошаговый экспорт куков из браузера

### Вариант 1: Google Chrome / Яндекс.Браузер / Edge / Brave

1. Откройте браузер и убедитесь, что вы залогинены в свой аккаунт на [music.youtube.com](https://music.youtube.com).
2. Установите расширение для экспорта куков в формате Netscape:
   * Рекомендуемое: **«Get cookies.txt locally»** ([Ссылка на Chrome Web Store](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbngbenkjcffliehddfaccca))
   * Или расширение: **«Cookie-Editor»**.
3. Находясь на вкладке [music.youtube.com](https://music.youtube.com), нажмите на иконку расширения в панели браузера.
4. Нажмите кнопку **«Export»** (или **«Export as cookies.txt»**).
5. Сохраните файл на диск с именем `cookies.txt`.

---

### Вариант 2: Mozilla Firefox

1. Откройте Firefox и войдите в [music.youtube.com](https://music.youtube.com).
2. Установите дополнение **«Cookie-Editor»** ([Ссылка на Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/cookie-editor/)).
3. Откройте расширение на вкладке YouTube Music.
4. Нажмите **Export** → выберите формат **Netscape Format**.
5. Сохраните полученный файл как `cookies.txt`.

---

## Как передать cookies.txt в SyncWave

### Способ А: Через веб-интерфейс (Рекомендуемый)

1. Откройте веб-панель SyncWave (например, `http://localhost:8080`).
2. В левом боковом меню перейдите в раздел **Настройки** (Settings).
3. В карточке **YouTube Session & Cookies** просто перетащите сохраненный файл `cookies.txt` в пунктирную область (или кликните для выбора файла).
4. Статус мгновенно изменится на **ACTIVE** с зеленой индикацией.

---

### Способ Б: Напрямую в директорию данных (Docker / Сервер)

Вы можете просто скопировать файл в директорию `/data` вашего сервера:

```bash
cp /путь/к/cookies.txt ./data/cookies.txt
chmod 600 ./data/cookies.txt
```

Сервер автоматически подхватит файл при следующей задаче синхронизации.

---

## Важные замечания о безопасности и сроке жизни

* **Срок действия**: Куки Google обычно активны несколько месяцев. Если через долгое время синхронизация плейлиста «Понравившиеся» начнет выдавать ошибку авторизации, достаточно просто заново экспортировать свежие куки из браузера и загрузить их через панель настроек.
* **Безопасность**: Файл `cookies.txt` содержит секретные токены вашей сессии. SyncWave хранит этот файл исключительно локально на вашем сервере в защищенной директории `/data` и никуда его не передает.
